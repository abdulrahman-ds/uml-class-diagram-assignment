# Community Aid Management System

A UML class modelling project for a community initiative that manages household aid requests, available aid items, and deliveries handled by volunteers.

## Purpose and scope

The proposed system centralises household records, request review, stock quantities, and distribution records. Eligibility and priority decisions remain with authorised staff. Financial donations, purchasing, live tracking, and implementation of a working application or SQL database are excluded.

## Main classes

Household, AidRequest, AidItem, Volunteer, Distribution, and DistributionLine.
